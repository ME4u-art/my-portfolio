## 💡 **Customization Tips**

### Change Animation Speed:
Edit the animation duration in CSS:
```css
animation: float 8s ease-in-out infinite; /* Change 8s */
```

### Adjust Glow Intensity:
Modify the rgba values:
```css
box-shadow: 0 20px 40px rgba(0, 170, 255, 0.2); /* Change 0.2 */
```

### Modify 3D Rotation:
Adjust the rotate values:
```css
transform: translateY(-12px) rotateX(5deg) rotateY(-5deg);
```
